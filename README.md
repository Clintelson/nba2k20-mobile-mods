# NBA 2K20 Mobile Mods

Mods for NBA 2K20 Mobile, organized by release version.

## Downloads

Open [`releases/`](releases/) and choose a version folder. Each folder contains the files and notes for that release.

## Releases

### v1.1.0

2026-27 NBA roster: 30 teams, 518 players, 363 new player profiles with complete in-game models. Includes all v1.0.0 mods. Three ways to install: the APK (easiest; replacing the original game starts you fresh), phone only, or with a computer (both keep your saves).

See [`releases/v1.1.0/README.md`](releases/v1.1.0/README.md).

### v1.0.0

First release. Planned contents:

- Boosted players
- MyCAREER coaching enabled
- Unlimited money
- All badges unlocked

**Supported game version:** Android 9.0 or higher is recommended, along with at least 4 GB of RAM and 5 GB of free storage.

See [`releases/v1.0.0/README.md`](releases/v1.0.0/README.md) for installation notes and compatibility details.
